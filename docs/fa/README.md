# مستندات TELBOTV2 — فارسی

[🇬🇧 English](../en/README.md) · 🇮🇷 **فارسی** · [فهرست اصلی مخزن](../../README.md)

Workers + D1، با پروژن خودکار روی پنل **PasarGuard** و پرداخت کارت‌به‌کارت که
عمداً **دستی** (تأیید ادمین) است.

## قواعد خواندن

- شناسه‌های فنی — فرمان‌ها، نام env، مسیر فایل‌ها، SQL و مقادیر callback — در
  مستندات فارسی هم **عیناً** به همان شکل انگلیسی می‌آیند و ترجمه نمی‌شوند.
- هر گزارهٔ فنی در این صفحات به فایلی در همین مخزن قابل ردیابی است (مسیرها
  در متن آمده). مواردی که از مخزن قابل استنباط نیستند (مثلاً آیا D1
  پروداکشنی وجود دارد) صریحاً «از مخزن قابل تشخیص نیست» نامیده می‌شوند؛
  حدس نمی‌زنیم.
- هیچ مقدار واقعیِ secret در هیچ صفحه‌ای نیست؛ همه مثال‌ها placeholder
  صریح (`<...>`) هستند.
