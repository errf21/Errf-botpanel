# مدیریت چند پنل PasarGuard با API Key

این نسخه تا ۱۰۰ پنل مستقل (شامل پنل قدیمی) را پشتیبانی می‌کند. همه پنل‌ها از
`X-Api-Key` استفاده می‌کنند؛ ورود نام کاربری/رمز عبور و دریافت توکن حذف شده است.
تنظیمات فعلی `PASARGUARD_PANEL_URL` و `PASARGUARD_API_KEY` را تغییر ندهید.

تنظیم یک‌باره: سکرت `PANEL_ENCRYPTION_KEY` شامل ۳۲ بایت تصادفی به صورت Base64،
متغیر `PANEL_ADMIN_ORIGIN` شامل دامنه HTTPS همین Worker، و در صورت نیاز
`PANEL_ADMIN_IDS` شامل شناسه‌های عددی ادمین. کلید رمزگذاری را خارج از Git نگه
دارید و پشتیبان امن بگیرید. افزودن پنل‌های بعدی به متغیر جدید یا انتشار مجدد نیاز ندارد.
`PANEL_ALLOWED_ORIGINS` و `PANEL_PASSWORD_LOGIN_SAFE` دیگر استفاده نمی‌شوند.

در گفت‌وگوی خصوصی `/panels` را باز کنید. گزینه افزودن، فرم امن Telegram Mini App
را نمایش می‌دهد؛ نام، دامنه HTTPS، شناسه گروه‌های پنل و API Key را وارد کنید.
کلید را در پیام معمولی تلگرام ارسال نکنید. سرور امضای initData و شناسه ادمین را
بررسی می‌کند و پیش از ذخیره رمزگذاری‌شده، اتصال و مجوزها را آزمایش می‌کند.
پنل تازه ابتدا غیرفعال است؛ فعال‌سازی و انتخاب برای سرویس‌های جدید نیاز به تأیید دارد.

هر سفارش پیش از اولین عملیات خارجی به یک شناسه ثابت پنل متصل می‌شود. تغییر
پنل پیش‌فرض، سرویس‌ها یا تلاش مجدد سفارش‌های قبلی را جابه‌جا نمی‌کند. تمدید،
خرید مجدد، ریست، حذف، وضعیت و اعلان‌ها از پنل اصلی همان سرویس استفاده می‌کنند.
هیچ جایگزینی خودکار پس از خطا انجام نمی‌شود.

حذف فقط برای پنل غیرمنتخب و فاقد هرگونه سفارش وابسته، حتی سابقه یا عملیات
معلق، مجاز است. پنل قدیمی حذف نمی‌شود. دامنه پنل دارای سفارش قابل تغییر نیست؛
برای مقصد جدید پنل جدا اضافه کنید. غیرفعال‌سازی فقط سفارش جدیدِ تخصیص‌نیافته را
متوقف می‌کند و مدیریت سرویس‌های قبلی را قطع نمی‌کند.

مهاجرت `0020` بدون تغییر باقی مانده و مهاجرت جدید `0021` محدودیت دو پنل و
ستون‌های رمز عبور/توکن را حذف می‌کند. شناسه پنل دوم قبلی و ارتباط سرویس‌ها حفظ
می‌شود؛ در صورت استفاده قبلی از رمز عبور باید همان شناسه را با API Key تنظیم
کنید. پیش از مهاجرت پشتیبان بگیرید، عملیات را متوقف و تخلیه کنید و فقط پس از
تأیید، مهاجرت و انتشار تولید را انجام دهید. هیچ تغییر تولیدی در این کار انجام نشده است.

راهنمای کامل نصب، محدودیت‌ها، امنیت DNS، پشتیبان و بازگشت امن در
[راهنمای انگلیسی](../en/multi-panel.md) آمده است. تست اتصال فقط بررسی خواندنی
مجوزهای اعلام‌شده است و اثبات عملکرد زنده همه عملیات روی پنل واقعی نیست.
