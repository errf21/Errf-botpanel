GET /api/groups/simple, requiring groups.read_simple. Template permissions are
separate. The existing X-Api-Key header, GET method and offset/limit are correct.

been independently verified; this is not a claim of a successful live fix.

  timeouts, secret redaction and cross-panel isolation remain intact.
- Simple groups explicitly carry statusVerified=false: IDs/names are available,
  but disabled status is unknown. UI shows an honest localized warning and blocks
  unverified saving. Direct API calls still cannot bypass full-detail checks.

  not ok or a misleading missing selection. Existing saved selections remain.
- Detail 403 and account-check 403 have separate localized diagnostics. Removed
  instructions to enable an assumed/nonexistent additional permission toggle.
- Migration group-status checks are unchanged: simple list is not proof that a
  destination group is enabled. This safety limitation is deliberately preserved.
